# React + Vite

This web application fetches movies from the first page of The Movie Database (TMDB) and displays them in a styled grid of cards, default sorted to newest first.
There is a filter option to find movies by genre, and you can find more information on the title and release date by hovering your mouse over the card.

To run the application, follow the steps below:

1. Create a .env file with an API_KEY to access the database (**use VITE_TMDB_API_KEY as the variable name**)
2. Run npm install
3. Run npm start

Then you can access the webpage locally.
